2. SYSTEM REQUIREMENTS

[Demo Image: System requirements checklist showing device, browser, and internet connection requirements]

Overview

Before using MyMasjidApp, it is important to ensure your device and software meet the minimum system requirements. Meeting these requirements ensures the system runs smoothly, displays correctly, and provides the best possible experience.

Supported Devices

MyMasjidApp is a web-based application that works on multiple device types:

Desktop and Laptop Computers

Desktop and laptop computers provide the best experience for using MyMasjidApp. The larger screen size makes it easier to view information, complete forms, and navigate between sections. Any modern desktop or laptop computer will work, including:
- Windows computers running Windows 10 or later
- Mac computers running macOS 10.14 or later
- Linux computers with a modern web browser installed

Tablet Devices

Tablet devices work well for viewing information and completing basic tasks. The touch interface makes navigation intuitive. Supported tablets include:
- iPad devices running iOS 12 or later
- Android tablets running Android 8.0 or later
- Windows tablets running Windows 10 or later

Smartphone Devices

Smartphones can be used to access the system for viewing information and completing simple tasks. However, some features may be easier to use on larger screens. Supported smartphones include:
- iPhone devices running iOS 12 or later
- Android phones running Android 8.0 or later

Browser Requirements

MyMasjidApp works best with modern, up-to-date web browsers. The following browsers are fully supported and recommended:

Google Chrome

Google Chrome is the recommended browser for the best experience. Chrome provides excellent compatibility, fast performance, and regular security updates. Use version 90 or later for optimal performance.

Mozilla Firefox

Mozilla Firefox is fully supported and provides excellent performance. Use version 88 or later for best results. Firefox is a good alternative if you prefer not to use Chrome.

Microsoft Edge

Microsoft Edge is fully supported, especially on Windows computers. The modern version of Edge provides excellent compatibility. Use version 90 or later.

Safari

Safari works well on Mac computers and iOS devices. Use Safari 14 or later on Mac, and Safari on iOS 12 or later on iPhone and iPad devices.

Browser Settings

To ensure the system works properly, configure your browser with these settings:
- Enable JavaScript (required for all features)
- Allow cookies (required for login and session management)
- Enable pop-ups for the system website (required for some features like printing)
- Allow location access if using location-based features

How to Check Your Browser Version

To check your browser version:
1. Open your web browser
2. Click on the menu button (usually three dots or lines in the top right corner)
3. Look for About or Help in the menu
4. Click on About to see your browser version
5. Compare your version to the requirements listed above

If your browser version is older than recommended, update it to the latest version for best performance and security.

Internet Connection Requirements

MyMasjidApp requires a stable internet connection to function. The connection is used to:
- Load the application interface
- Access your account and data
- Save changes you make
- Sync information across devices
- Receive real-time updates

Connection Speed

For basic use, a minimum connection speed of 1 Mbps is recommended. This allows the system to load pages and display information without significant delays.

For optimal performance, especially when uploading files or viewing reports, a connection speed of 5 Mbps or higher is recommended. Faster connections provide quicker page loads and smoother experience.

Connection Type

Any type of internet connection will work, including:
- Broadband or DSL connections
- Cable internet
- Fiber optic internet
- Mobile data connections (4G or 5G)
- Wi-Fi connections

Connection Stability

A stable connection is more important than raw speed. Interruptions in your connection can cause:
- Loss of unsaved work
- Login failures
- Slow page loading
- Error messages

If you experience frequent connection problems, consider using a more stable connection type or checking your network setup.

Screen Resolution

MyMasjidApp is designed to work on various screen sizes, but optimal viewing requires certain minimum resolutions:

Desktop and Laptop

For desktop and laptop computers, a minimum screen resolution of 1366 by 768 pixels is recommended. Higher resolutions provide better clarity and more screen space for information. The system works best on resolutions of 1920 by 1080 pixels or higher.

Tablet

Tablets typically have sufficient resolution for viewing the system. Most modern tablets meet the requirements automatically.

Smartphone

Smartphones will display the system, but some features may require scrolling or zooming on smaller screens. The system is optimized for mobile viewing, but a larger screen provides a better experience.

Display Settings

For best viewing experience:
- Set your display brightness to a comfortable level
- Adjust text size in your browser if needed (but note that the system has its own text sizing)
- Use full screen mode when possible for more viewing space
- Ensure proper contrast for readability

JavaScript Requirements

JavaScript must be enabled in your browser for MyMasjidApp to function. JavaScript is used for:
- Interactive features and buttons
- Form validation
- Dynamic content loading
- User interface interactions
- Real-time updates

JavaScript is enabled by default in all modern browsers. If you have disabled it, you must enable it to use the system.

How to Enable JavaScript

To enable JavaScript:
1. Open your browser settings
2. Look for Privacy and Security or Advanced settings
3. Find Content Settings or Site Settings
4. Ensure JavaScript is enabled
5. Refresh the MyMasjidApp page

If you are unsure how to enable JavaScript in your specific browser, search online for instructions for your browser type and version.

Cookie Requirements

Cookies must be enabled for MyMasjidApp to function properly. Cookies are used for:
- Maintaining your login session
- Remembering your preferences
- Storing temporary information
- Security features

Cookies are enabled by default in all browsers. If you have disabled cookies, you must enable them to use the system.

How to Enable Cookies

To enable cookies:
1. Open your browser settings
2. Look for Privacy and Security settings
3. Find Cookie settings
4. Ensure cookies are enabled (usually set to Allow all cookies or similar)
5. Refresh the MyMasjidApp page

Location Services

Some features in MyMasjidApp use location services, such as:
- Staff check-in verification
- Location-based attendance recording
- GPS tracking for certain activities

If you use these features, you must allow location access when prompted by your browser. Location access is optional and only required for specific features.

How to Enable Location Services

To enable location services:
1. When the system requests location access, click Allow or Yes
2. In your browser settings, ensure location permissions are granted for the MyMasjidApp website
3. On mobile devices, ensure location services are enabled in your device settings

Security Considerations

For secure access to MyMasjidApp:
- Use a secure, private internet connection when possible
- Avoid using public Wi-Fi networks for sensitive operations
- Keep your browser updated for security patches
- Use strong passwords (see Security and Privacy section)
- Log out when finished, especially on shared devices

If you must use a public network, consider using a virtual private network (VPN) for additional security.

System Compatibility Summary

To use MyMasjidApp, you need:
- A device with internet access (computer, tablet, or smartphone)
- A modern web browser (Chrome, Firefox, Edge, or Safari)
- An internet connection (minimum 1 Mbps recommended)
- JavaScript enabled in your browser
- Cookies enabled in your browser
- Screen resolution appropriate for your device type

If you meet these requirements, you are ready to use MyMasjidApp. If you have questions about your specific setup, contact your system administrator for assistance.

Testing Your Setup

Before using the system for important tasks, test your setup:
1. Open your web browser
2. Navigate to the MyMasjidApp website
3. Verify the page loads correctly
4. Check that all visual elements display properly
5. Try logging in to verify connectivity
6. Test a basic function to ensure everything works

If you encounter any issues during testing, refer to the Troubleshooting Guide section or contact your system administrator.
3. INSTALLATION AND SETUP

[Demo Image: System installation screen showing setup options]

Overview

MyMasjidApp is a web-based application that does not require installation on your computer. You access the system through your web browser using the web address provided by your institution. However, you do need to set up your account and configure your browser for the best experience.

No Software Installation Required

Unlike traditional software, MyMasjidApp runs entirely in your web browser. This means:
- You do not need to download or install any software
- You do not need to update the application manually
- Updates happen automatically on the server
- You can access the system from any device with internet access
- Your data is stored securely on the server, not on your device

Accessing the System

Step 1: Get the Web Address

1. Contact your system administrator or institution
2. Ask for the MyMasjidApp web address
3. Write down the web address for future reference
4. The web address typically looks like: https://yourmasjid.com or https://mymasjidapp.com

Step 2: Open Your Web Browser

1. Launch your preferred web browser (Chrome, Firefox, Edge, or Safari)
2. Ensure your browser is updated to the latest version
3. Close any unnecessary browser tabs for better performance

Step 3: Navigate to the System

1. Click in the address bar at the top of your browser
2. Type or paste the MyMasjidApp web address
3. Press Enter on your keyboard
4. Wait for the login page to load
5. You should see the MyMasjidApp login interface

If the page does not load:
- Verify you entered the web address correctly
- Check your internet connection
- Try refreshing the page
- Contact your system administrator if problems persist

Browser Configuration

Before using MyMasjidApp, configure your browser for optimal experience:

Enable JavaScript

1. JavaScript must be enabled for the system to work
2. Most browsers enable JavaScript by default
3. If JavaScript is disabled, enable it in your browser settings
4. See the System Requirements section for detailed instructions

Enable Cookies

1. Cookies must be enabled for login and session management
2. Most browsers enable cookies by default
3. If cookies are disabled, enable them in your browser settings
4. See the System Requirements section for detailed instructions

Allow Pop-ups

1. Some features require pop-up windows
2. Allow pop-ups for the MyMasjidApp website
3. Configure this in your browser settings under Site Permissions
4. Pop-ups are needed for printing reports and viewing detailed information

Enable Location Services (Optional)

1. Location services are optional but required for some features
2. Features that use location include staff check-in and attendance tracking
3. Allow location access when prompted by your browser
4. You can deny location access if you do not use these features

Account Registration

Step 1: Access the Registration Page

1. Navigate to the MyMasjidApp login page
2. Look for a Register or Daftar link
3. Click on the Register link
4. You will be taken to the registration page

Step 2: Fill Out Registration Form

1. Enter your IC Number (12-digit Malaysian identity card number)
2. You can enter it with or without hyphens (e.g., 051003060229 or 051003-06-0229)
3. Enter your full name as it appears on your identity card
4. Enter your email address (optional but recommended)
5. Enter your phone number (optional but recommended)
6. Enter your age (optional)
7. Create a password (at least 6 characters)
8. Confirm your password by entering it again

Step 3: Submit Registration

1. Review all information you entered
2. Verify your IC number is correct
3. Ensure your password is strong and secure
4. Click the Register or Submit button
5. Wait for the system to process your registration

Step 4: Registration Confirmation

1. If registration is successful, you will see a confirmation message
2. You may be redirected to the login page automatically
3. Your account may require administrator approval
4. If approval is required, wait for notification from your administrator
5. Once approved, you can log in to the system

Registration Requirements

IC Number Requirements:
- Must be exactly 12 digits
- Can include hyphens for formatting
- Must be unique (not already registered)
- Must be a valid Malaysian identity card number format

Name Requirements:
- Must match the name on your identity card
- Use full name, not nickname
- Capitalize first letters of each name component

Email Requirements (Optional):
- Must be a valid email format (e.g., name@example.com)
- Must be unique if provided
- Recommended for password recovery

Password Requirements:
- Minimum 6 characters
- Can include letters, numbers, and special characters
- Should be strong and secure
- Must match the confirmation password

Common Registration Errors

If Registration Fails with IC Already Registered:
- Your IC number may already be in the system
- Try logging in instead of registering
- Contact your administrator if you cannot log in
- Your account may need to be activated

If Registration Fails with Invalid IC Format:
- Verify your IC number is exactly 12 digits
- Check for typing errors
- Remove any spaces or extra characters
- Enter only numbers and hyphens

If Registration Fails with Weak Password:
- Ensure your password is at least 6 characters long
- Try adding numbers or special characters
- Make sure the password and confirmation match
- Avoid using personal information in your password

If Registration Fails with Email Already Registered:
- The email address is already in use
- Try logging in with your existing account
- Use a different email address
- Contact your administrator for assistance

First-Time Login

After successful registration:

Step 1: Navigate to Login Page

1. Go to the MyMasjidApp web address
2. You should see the login page
3. If you are already on the login page, proceed to Step 2

Step 2: Enter Your Credentials

1. Enter your IC number in the IC Number field
2. Enter your password in the Password field
3. If you have multiple roles, select your role from the dropdown
4. Click the Login button

Step 3: Complete Your Profile

1. After logging in, you may be prompted to complete your profile
2. Fill in any missing information
3. Verify your contact details are correct
4. Save your profile information
5. You may be redirected to the dashboard after completing your profile

Profile Completion

Some information may be required to complete your profile:
- Email address (if not provided during registration)
- Phone number (if not provided during registration)
- Address (optional but recommended)
- Emergency contact information (optional)

Complete all required fields before proceeding. Optional fields can be filled in later. Keep your profile information current for important notifications and account recovery.

Account Approval

If your account requires approval:
1. Your registration will be marked as pending
2. An administrator will review your registration
3. You will receive a notification when your account is approved
4. Once approved, you can log in normally
5. Contact your administrator if approval takes longer than expected

Bookmarking the System

For easy access, bookmark the MyMasjidApp website:

Step 1: While on the MyMasjidApp login page

1. Click the star icon in your browser address bar
2. Or press Ctrl+D (Windows/Linux) or Cmd+D (Mac)
3. The bookmark dialog will appear

Step 2: Save the Bookmark

1. Choose a name for the bookmark (e.g., MyMasjidApp)
2. Select a folder to save the bookmark (optional)
3. Click Save or Done
4. Your bookmark is now saved

Step 3: Access the Bookmark

1. Click the bookmarks menu in your browser
2. Find your MyMasjidApp bookmark
3. Click on it to open the system
4. You can also add it to your bookmarks toolbar for one-click access

Setting Up Multiple Devices

You can access MyMasjidApp from multiple devices:

Desktop or Laptop Computer:
1. Follow the browser configuration steps above
2. Bookmark the system for easy access
3. Log in using your credentials
4. Your preferences will sync across devices

Tablet Device:
1. Open your tablet web browser
2. Navigate to the MyMasjidApp web address
3. Bookmark the page for easy access
4. Log in using your credentials
5. The interface will adapt to your tablet screen size

Smartphone Device:
1. Open your smartphone web browser
2. Navigate to the MyMasjidApp web address
3. Add the page to your home screen for app-like access
4. Log in using your credentials
5. The interface will be optimized for mobile viewing

Important Notes:
- You can be logged in on multiple devices simultaneously
- Your session remains active on each device independently
- Log out from shared devices when finished
- Keep your login credentials secure

Troubleshooting Setup Issues

If You Cannot Access the Website:
- Verify your internet connection is working
- Check that you entered the web address correctly
- Try accessing the website from a different browser
- Clear your browser cache and cookies
- Contact your system administrator

If Registration Does Not Work:
- Verify all required fields are filled correctly
- Check that your IC number format is correct
- Ensure your password meets the requirements
- Try using a different web browser
- Contact your system administrator for assistance

If Login Does Not Work After Registration:
- Your account may require administrator approval
- Wait for approval notification
- Try logging in after 24 hours
- Contact your administrator to check account status
- Verify you are using the correct IC number and password

8. USER ROLES AND PERMISSIONS

[Demo Image: User roles and permissions matrix showing different access levels]

Overview

MyMasjidApp uses a role-based access control system. Each user has one or more roles that determine what features they can access and what actions they can perform. Understanding roles and permissions helps you know what you can do in the system.

Available Roles

Student Role:

The student role is for registered students. Students can:
- View their own information
- View their attendance records
- View their fee records
- Pay fees online
- View their exam results
- Download result slips
- View announcements
- Update their profile information
- Change their password

Students cannot:
- View other students' information
- Mark attendance
- Enter exam results
- Manage classes or users
- Access administrative functions

Teacher Role:

The teacher role is for registered teachers. Teachers can:
- View their assigned classes
- View students in their classes
- Mark attendance for their classes
- Enter exam results for their classes
- Upload attendance proof photos
- Upload result slips
- View class statistics
- View announcements
- Update their profile
- Change their password

Teachers cannot:
- Create or delete classes
- Manage users
- View all system data
- Access administrative functions
- Modify system settings

Administrator Role:

The administrator role has full system access. Administrators can:
- Manage all users (create, edit, delete)
- Manage all students
- Manage all teachers
- Create and manage classes
- View all attendance records
- Generate and manage fees
- Create exams
- View all results
- Create announcements
- Configure system settings
- Export data and generate reports
- View audit logs and admin actions
- Archive academic years
- Manage backups

Administrators have access to all features and can perform all actions in the system.

Payment Approver (IB) Role:

The IB (Imam Bilal) role is for payment approvers. IB users can:
- View payment reports
- Confirm fee payments
- Verify payment documentation
- Approve or reject payments
- View payment history
- View class reports
- View announcements

IB users cannot:
- Create or modify fees
- Manage users
- Mark attendance
- Enter exam results
- Access administrative functions

PIC (Person in Charge) Role:

The PIC role has special administrative permissions. PIC users can:
- Manage students in their area
- View and manage attendance
- View and manage fees
- Approve registrations
- Manage user roles (limited)
- View reports
- Access PIC-specific functions

Multiple Roles

Users can have multiple roles simultaneously. For example:
- A user can be both a teacher and an administrator
- A user can be a student and also have teacher permissions
- Roles are assigned based on responsibilities

When a user has multiple roles:
- They can switch between roles using the role selector
- Each role has its own permissions
- The active role determines what features are available
- Users select their role during login

Role Selection

During Login:

1. Enter your IC number and password
2. If you have multiple roles, a role dropdown appears
3. Select the role you want to use for this session
4. Click Login
5. The system will open with the selected role's permissions

Changing Roles During Session:

1. Click on your name in the top right corner
2. Select Switch Role or Tukar Peranan
3. Choose the role you want to use
4. The system will refresh with the new role's permissions
5. Some pages may redirect based on role

Permission Levels

Read-Only Permissions:

Some features allow read-only access:
- Users can view information but cannot modify it
- Examples: Students viewing their own data
- Some reports are read-only

Edit Permissions:

Some features allow editing:
- Users can view and modify information
- Examples: Teachers editing their class information
- Changes are tracked in the audit log

Full Control Permissions:

Full control allows all actions:
- Create, read, update, and delete
- Examples: Administrators managing all data
- All actions are logged

Role-Specific Features

Dashboard Features:

- Students see: Personal attendance, fees, results
- Teachers see: Their classes, student lists, tasks
- Administrators see: System-wide statistics, all data
- IB see: Payment reports, pending approvals

Menu Items:

- Different roles see different menu items
- Menu items are filtered based on permissions
- Hidden items are not accessible
- Some items are available but show limited data

Data Access:

- Students see only their own data
- Teachers see data for their classes only
- Administrators see all data
- IB see payment-related data only

Understanding Your Role

To see what role you have:

1. Look at the top right corner of the screen
2. Your role is displayed next to your name
3. Click on your name to see all available roles
4. The current active role determines your permissions

To understand what you can do:

1. Review this manual's role-specific sections
2. Check the features available in your menu
3. Contact your administrator for clarification
4. Try accessing features to see what is available

Requesting Role Changes

If you need different permissions:

1. Contact your system administrator
2. Explain why you need additional permissions
3. Administrator will review your request
4. If approved, your role will be updated
5. Log out and log back in to see changes

Role Security

Roles are secure:
- Only administrators can assign roles
- Role changes are logged
- Permissions are enforced by the system
- Users cannot change their own roles
- Role assignments require administrator approval

13. FREQUENTLY ASKED QUESTIONS

[Demo Image: FAQ page showing common questions and answers]

General Questions

Q: What is MyMasjidApp?

A: MyMasjidApp is a comprehensive web-based management system for masjids and madrasahs. It helps institutions manage students, teachers, classes, attendance, fees, exams, and results in one centralized platform.

Q: Who can use MyMasjidApp?

A: MyMasjidApp is designed for:
- Students enrolled in madrasah programs
- Teachers teaching classes
- Administrators managing the institution
- Payment approvers (IB) confirming payments
- Staff members checking in for work

Q: Do I need to install software?

A: No, MyMasjidApp is a web-based application. You only need a web browser and internet connection. No software installation is required.

Q: What browsers are supported?

A: MyMasjidApp works with:
- Google Chrome (recommended)
- Mozilla Firefox
- Microsoft Edge
- Safari (Mac and iOS)

Q: Can I use MyMasjidApp on my phone?

A: Yes, MyMasjidApp works on smartphones, tablets, and computers. The interface adapts to your device screen size.

Account and Login Questions

Q: How do I create an account?

A: Click Register on the login page, fill in your information (IC number, name, email, password), and submit. Your account may require administrator approval before you can log in.

Q: What if I forget my password?

A: Click Forgot Password on the login page, enter your IC number, choose recovery method (Email or SMS), and follow the instructions sent to you.

Q: Can I change my password?

A: Yes, log in and go to Personal Settings, click Password tab, enter your current password and new password, then save.

Q: What if I forget my IC number?

A: Contact your system administrator. They can help you recover your account using your name or email address.

Q: Can I have multiple accounts?

A: No, each IC number can only have one account. However, you can have multiple roles (e.g., student and teacher) on the same account.

Q: Why is my account pending?

A: New accounts require administrator approval. Wait for approval notification, or contact your administrator to check approval status.

Student Questions

Q: How do I view my attendance?

A: Click Attendance or Kehadiran in the menu. You will see your attendance records. Use filters to view by date range.

Q: How do I check my fees?

A: Click Fees or Yuran in the menu. You will see all your fee records, including paid and outstanding fees.

Q: How do I pay fees online?

A: Go to Fees page, find the outstanding fee, click on it, click Pay Now, select payment method, enter payment details, and confirm.

Q: How do I view my exam results?

A: Click Results or Keputusan in the menu. You will see all your exam results with marks and grades.

Q: Can I download my result slips?

A: Yes, if result slips are uploaded, you can view and download them from the Results page.

Q: How do I update my profile?

A: Go to Personal Settings, click Profile tab, make changes, and click Save.

Teacher Questions

Q: How do I mark attendance?

A: Click Attendance in the menu, select your class and date, mark each student's status, and click Save.

Q: Can I upload attendance proof photos?

A: Yes, when marking attendance, you can upload photos as proof. Click the upload button and select your photo.

Q: How do I enter exam results?

A: Go to Results page, select the exam, click Enter Results, enter marks for each student, and click Save.

Q: Can I upload result slips?

A: Yes, when entering results, you can upload result slip images. Click upload button and select your file.

Q: How do I view my class list?

A: Click Classes or Kelas in the menu. You will see all classes assigned to you. Click on a class to see the student list.

Q: Can I see attendance statistics for my class?

A: Yes, go to Attendance page, select your class, and view statistics including attendance rates and patterns.

Administrator Questions

Q: How do I add a new student?

A: Go to Students page, click Add Student, fill in the information, and click Save.

Q: How do I create a new class?

A: Go to Classes page, click Create Class, fill in class details (name, level, schedule, fee), and click Save.

Q: How do I generate monthly fees?

A: Go to Fees page, click Generate Fees, select month and classes, review amounts, and click Generate.

Q: How do I approve registrations?

A: Go to Pending Registrations page, review registration information, click Approve to activate account or Reject to deny.

Q: How do I export data?

17. GLOSSARY

[Demo Image: Glossary terms page]

Account: Your user account in the system, identified by your IC number and password.

Administrator: A user role with full system access and management permissions.

Announcement: System-wide or role-specific messages and notifications.

Attendance: Records of student presence in classes, marked by teachers.

Backup: A copy of system data saved for recovery purposes.

Class: A group of students learning together with assigned teacher and schedule.

Dashboard: The main page after login showing overview information and statistics.

Export: Downloading data from the system in various formats (Excel, PDF, etc.).

Fee: Monthly payment required from students for classes.

IB: Imam Bilal, a user role for payment approvers who confirm fee payments.

IC Number: Malaysian identity card number, 12 digits used as user identifier.

Import: Uploading data into the system from external files (CSV, etc.).

Login: The process of accessing the system using IC number and password.

Menu: Navigation panel showing available sections and features.

Password: Secret code used with IC number to log into the system.

PIC: Person in Charge, a user role with special administrative permissions.

Profile: Your personal information stored in the system.

Registration: The process of creating a new user account.

Report: Generated documents showing system data and statistics.

Result: Exam marks and grades for students.

Role: User type determining what features and data are accessible.

Session: Your active login period, typically lasting 24 hours.

Settings: Configuration options for personal preferences and system setup.

Student: A user role for enrolled students viewing their own data.

Teacher: A user role for teachers managing classes and entering data.

User: Any person with an account in the system.
