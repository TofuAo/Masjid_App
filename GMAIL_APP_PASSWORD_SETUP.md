# Gmail App Password Setup Guide

## Why You Need an App Password

When 2-Step Verification is enabled on Gmail, you **cannot** use your regular password for SMTP authentication. You must use a **Gmail App Password** instead.

## Step-by-Step: Generate a Gmail App Password

### Step 1: Go to Google Account Settings
1. Visit: https://myaccount.google.com/
2. Sign in with your Gmail account (the one you're using for `EMAIL_USER`)

### Step 2: Navigate to Security Settings
1. Click on **Security** in the left sidebar
2. Scroll down to **How you sign in to Google**
3. Find **2-Step Verification** (it should show "On")

### Step 3: Generate App Password
1. Scroll down to **App passwords** (or search for "App passwords" in the search bar)
2. You may need to sign in again
3. Under **Select app**, choose **Mail**
4. Under **Select device**, choose **Other (Custom name)**
5. Type: **MyMasjidApp** (or any name you prefer)
6. Click **Generate**

### Step 4: Copy the App Password
1. Google will display a **16-character password** (e.g., `abcd efgh ijkl mnop`)
2. **Copy this password** - you won't be able to see it again!
3. The password will look like: `abcd efgh ijkl mnop` (with spaces) or `abcdefghijklmnop` (without spaces)
4. **Remove any spaces** when using it

### Step 5: Update Your .env File
1. Open your `.env` file in the `backend` directory
2. Find the `EMAIL_PASSWORD` line
3. Replace it with your App Password (no spaces):
   ```
   EMAIL_PASSWORD=abcdefghijklmnop
   ```
4. Save the file

### Step 6: Restart Backend
After updating the `.env` file, restart your backend:
```bash
docker-compose restart backend
```

Or rebuild if needed:
```bash
docker-compose build backend
docker-compose up -d backend
```

## Important Notes

⚠️ **App Password vs Regular Password:**
- ❌ **DO NOT** use your regular Gmail password
- ✅ **DO** use the 16-character App Password generated by Google

⚠️ **Password Format:**
- App Passwords are 16 characters
- They may be displayed with spaces (`abcd efgh ijkl mnop`)
- Remove spaces when using: `abcdefghijklmnop`

⚠️ **Security:**
- App Passwords are specific to each app/device
- You can revoke them anytime from Google Account settings
- If you regenerate, you'll need to update your `.env` file

## Troubleshooting

### "Username and Password not accepted" Error
This means:
1. ❌ You're using your regular password instead of App Password
2. ❌ The App Password has spaces (remove them)
3. ❌ The App Password was copied incorrectly
4. ❌ 2-Step Verification is not enabled

**Solution:** Generate a new App Password and make sure to:
- Copy it exactly (no spaces)
- Update `.env` file
- Restart backend

### "App passwords" Option Not Visible
If you don't see "App passwords" option:
1. Make sure 2-Step Verification is **enabled**
2. You may need to verify your account with a phone number first
3. Try accessing directly: https://myaccount.google.com/apppasswords

### Testing Email Configuration
After setting up, test by:
1. Requesting a password reset from the app
2. Check backend logs for email sending status
3. Check your Gmail inbox (and spam folder)

**After Updating:**
```bash

```

## Still Having Issues?

If you're still getting authentication errors after following these steps:
1. Double-check that 2-Step Verification is enabled
2. Generate a **new** App Password
3. Make sure there are **no spaces** in the password
4. Restart the backend container
5. Check backend logs: `docker-compose logs backend --tail=50`
