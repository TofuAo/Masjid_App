# Word Document Formatting Instructions

## How to Convert Markdown to Word with Proper Formatting

### Step 1: Convert Markdown to Word
1. Open the `INDUSTRIAL_TRAINING_REPORT.md` file
2. Use one of these methods:
   - **Pandoc** (recommended): `pandoc INDUSTRIAL_TRAINING_REPORT.md -o INDUSTRIAL_TRAINING_REPORT.docx`
   - **Online converter**: Use markdown to Word converter online
   - **Copy-paste**: Copy content to Word and format manually

### Step 2: Apply Formatting in Microsoft Word

#### Page Setup
- **Margins:**
  - Left: 2.5 cm
  - Right: 2.5 cm
  - Top: 3.0 cm
  - Bottom: 2.5 cm
- **Page Size:** A4
- **Orientation:** Portrait

#### Font Settings
- **Font:** Times New Roman
- **Size:** 12 pt
- **Apply to:** Entire document (Select All → Format → Font)

#### Headings Formatting
- **Heading 1:** Times New Roman, 14pt, Bold
- **Heading 2:** Times New Roman, 13pt, Bold
- **Heading 3:** Times New Roman, 12pt, Bold
- **Body Text:** Times New Roman, 12pt, Regular

#### Line Spacing
- **Body Text:** 1.5 line spacing
- **Paragraph Spacing:** 6pt after paragraphs

#### Page Breaks
- Insert page breaks before major sections
- Ensure figures and tables are properly placed

#### Table Formatting
- Use Word's table feature
- Center align table titles
- Apply borders as needed
- Use Times New Roman 12pt for table text

#### Cover Page
- Create separate cover page
- Include UMP logo (insert image)
- Center align all text
- Use larger font for title

#### Page Numbers
- Start page numbering from page 1 (after cover page)
- Use footer for page numbers
- Format: "Page X of Y" or just "X"

### Step 3: Add Required Elements

1. **Front Cover:**
   - UMP logo (top center)
   - Title: "INDUSTRIAL TRAINING REPORT"
   - Company name
   - Student name and ID
   - Date

2. **Back Cover:**
   - Leave blank or add decorative element

3. **Table of Contents:**
   - Use Word's automatic TOC feature
   - Update after all formatting is done

4. **List of Tables:**
   - Manually create or use Word's table of figures

5. **List of Figures:**
   - Manually create or use Word's table of figures

6. **Gantt Chart:**
   - Create in Excel or use Word's table feature
   - Format with colors/shading for timeline visualization
