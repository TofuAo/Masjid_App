📊 Database Overview

Total Tables: 10 core tables

Core Relationships

  • users - Central master table for all people (students, teachers, admins)
  • students - Extension of users with class enrollment information
  • teachers - Extension of users with expertise information
  • classes - Classes taught by teachers, enrolled by students
  • attendance - Tracks student attendance in classes
  • exams - Exams conducted for classes
  • results - Exam results for students
  • fees - Fee payments by students
  • announcements - System announcements created by users
  • staff_checkin - Staff check-in/check-out records with geolocation

Legend

PK = Primary Key
FK = Foreign Key
||--o{ = One-to-Many relationship
||--|| = One-to-One relationship

Key Features

  • All relationships use foreign key constraints for data integrity
  • Most relationships use ON DELETE CASCADE for automatic cleanup
  • Some relationships use ON DELETE SET NULL to preserve data (e.g., class assignments)
  • All tables include created_at and updated_at timestamps
  • Uses MySQL/MariaDB with InnoDB engine for transaction support
